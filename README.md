# ARC — Train. Track. Evolve.

Native Android workout tracker. This package is a complete repository replacement.

## Upload/build
Replace the contents of the existing ARC GitHub repository with the contents of this folder. Do not mix old Kotlin files with this version.

GitHub Actions workflow is included under `.github/workflows/build-apk.yml`.

## Included
- Muscle/equipment organized exercise library
- Exercise-specific local animated human demonstrations (offline)
- Custom plans, days, exercise order and per-exercise configuration
- Full-body and muscle-specific warm-up library
- Muscle-specific cool-down library
- Live workout logging and rest timer
- Goals, history, checklist, settings
- Existing ARC thumbnail

The app is deliberately self-contained: no external demo API is required for exercise animations.
